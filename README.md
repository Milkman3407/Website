# 3D Print Request Portal

A static starter site for browsing printable models, adding items to a cart, and preparing a request summary.

## Features

- Displays available printable models.
- Stores cart selections in the browser.
- Lets users review and remove cart items before preparing a request summary.

## Customize models

Edit `PRODUCTS` in `products.js` to update model names, descriptions, units, lead times, and card colors.
